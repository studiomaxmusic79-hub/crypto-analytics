# Проверка сборки — 15 октября 2026

## Подтверждено

- **22 автоматических теста пройдены.** Проверены UP/DOWN/WAIT, пропуски входных свечей, фиксированный порог оценки, исключение будущей свечи, дубликаты конкурентных вставок, сохранение и неизменяемость данных после повторного открытия SQLite, восстановление проверки после пропуска целевой свечи, разделение статистики WAIT, запрет SQLite на Render, ограничения параметров HTTP API и экспорт.
- **Реальный Binance доступен из среды проверки.** Через HTTP API приложения получено по 200 реальных часовых свечей BTCUSDT и ETHUSDT. Получены котировки обеих пар; сервис сформировал по два прогноза на реальных закрытых свечах. Точная историческая минутная цена для завершённого часа запрошена успешно.
- Синтаксис обоих JavaScript-файлов проверен Node. Через DOM-проверку с явно тестовыми ответами проверены загрузка цены, переключение BTC/ETH, интервала, ссылки экспорта, показ ошибки и маркировка устаревшего графика. Эти тестовые ответы в приложении не используются и в архив не включены.
- YAML Render разбирается; в нём только один Web Service с `plan: free`, без оплачиваемых дисков/воркеров/баз. `DATABASE_URL` запрашивается отдельно.
- Зависимости установлены на Python 3.12.14; `pip check` не выявил конфликтов. JavaScript и интерфейс не требуют CDN.

## Ограничения проверки

- Визуальный браузерный тест и проверка на физическом телефоне **не выполнены**: поддерживаемое управление браузером в этой среде недоступно. Адаптивная вёрстка реализована; внешний вид необходимо осмотреть после локального запуска или публикации.
- **Реальный PostgreSQL и развёртывание на Render не проверены.** В исходниках есть дополнительный тест `tests/test_postgres.py` для одноразовой локальной PostgreSQL: отдельно установите `pgserver==0.1.4` и запустите тест от обычного пользователя. Без этого пакета / при запуске от root он пропускается. Рабочее приложение `pgserver` не использует.
- Нет оснований оценивать предсказательную точность: ожидание полного горизонта 1ч/4ч в рамках проверки не проводилось. Оценивание и восстановление проверены на тестовых сценариях, а запрос целевой свечи — также на реальном Binance. Реальные результаты появятся только после накопления завершённых прогнозов.
- Тестовый клиент текущей Starlette сообщает предупреждение о будущей смене HTTPX на HTTPX2; проверки проходят, на работу приложения это не влияет.
- Архив не содержит историю, тестовые базы, реальные пароли, окружение Python или созданные облачные ресурсы. Инструкция в `README.md` описывает запуск и оставшиеся действия для публикации.
